# 🎯 AI Career Coach

AI Career Coach is a beginner-friendly AI-powered career analysis application built with Python, Streamlit, CrewAI, and Groq.

The application analyzes a user's resume and target job to identify relevant skills, skill gaps, career directions, and a personalized learning roadmap.

## ✨ Features

- Upload PDF or TXT resumes
- Enter a target job
- Add a job description
- Analyze relevant skills
- Identify skill gaps
- Recommend career directions
- Generate a personalized learning roadmap
- Suggest resume improvements
- Uses a single CrewAI agent
- Uses Groq's openai/gpt-oss-120b model
- Secure API key management through Streamlit Secrets
- No database or authentication required

## 🛠️ Tech Stack

- Python
- Streamlit
- CrewAI
- Groq
- GPT-OSS 120B
- pypdf
